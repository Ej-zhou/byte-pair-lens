How to read the map

One cell per character. Each row is every UTF-8 byte except the last (e.g. E4 B8); each column is the last byte, 80–BF, so a row holds 64 consecutive code points. The same rule covers 2-, 3- and 4-byte characters. A cell is blue when the selected tokenizer has that character as one whole token; otherwise the character is split into pieces of its bytes. A vermilion marker means the row prefix itself is a fragment token, so the characters in that row that aren't whole tokens cost two tokens instead of one per byte.
