Han characters by UTF-8 byte prefix

Each row is one 2-byte UTF-8 prefix (e.g. E4 B8), each column the third byte 80–BF, so a row holds 64 consecutive code points. A cell is blue when the selected tokenizer has that character as a whole token. Rows with an orange marker are prefixes that exist as a fragment token in the vocab, which is how the uncovered characters in that row get encoded.
